# 🔎 Project Overview
This project presents an interactive E-Commerce Sales Dashboard built using Power BI to analyze:

Year-to-Date (YTD) Sales
Profit & Profit Margin
Sales by Category
Regional Performance
Top & Bottom Products
Shipping Type Analysis
State-wise Sales Distribution

The dashboard enables business stakeholders to quickly monitor performance and identify growth opportunities.

# 🎯 Business Problem

E-commerce businesses generate large volumes of transactional data.
This dashboard helps answer key questions:

Are we growing compared to last year?
Which product categories drive the most revenue?
Which regions underperform?
Which products should be promoted or discontinued?
How does shipping mode affect revenue?
